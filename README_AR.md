# حارس — نموذج مراقبة لوحة كهربائية بالذكاء الاصطناعي

**حارس (HARIS)** نموذج أولي لمراقبة أربعة خطوط كهربائية افتراضية عبر قراءات جهد وتيار وحرارة متغيرة، مع اكتشاف السلوك غير الطبيعي وتصنيف الحالة إلى **طبيعي / تحذير / خطر** ثم عرض التشخيص والسبب المحتمل والإجراء المقترح.

## الموقع الحي

**GitHub Pages:** https://ramhalghamdy-source.github.io/Haris/

النسخة المنشورة تعمل بالكامل داخل المتصفح، ولا تعتمد على Render أو خادم Python. المتصفح يولد بيانات الحساسات الافتراضية، ويدرب أربعة نماذج Isolation Forest خفيفة، ثم يشغّل اكتشاف الشذوذ والتشخيص وتحديث الداشبورد مباشرة.

> هذه نسخة MVP تجريبية ببيانات محاكاة وليست نظام سلامة كهربائية إنتاجيًا.

## ما الذي يعمل في الموقع؟

- أربعة خطوط: التكييف والتبريد، أجهزة القياس الحساسة، الإضاءة، والمقابس وأجهزة الكمبيوتر
- قراءات حية للجهد والتيار والحرارة
- Isolation Forest مستقل لكل خط داخل المتصفح
- حالات طبيعي / تحذير / خطر
- Anomaly Score ورسوم اتجاه حية
- صفحة تشخيص تفاعلية
- سبب محتمل + إجراء مقترح
- تنبيه مرئي وسجل للأحداث
- حقن أعطال تجريبية: حمل زائد، هبوط جهد، ارتفاع جهد، وارتفاع حرارة
- زر إعادة الوضع الطبيعي

ملفات الموقع موجودة داخل مجلد `docs/`، ويتم نشرها تلقائيًا من GitHub عبر workflow موجود في `.github/workflows/pages.yml`.

## نسخة Python الأصلية

ما زالت موجودة داخل المستودع للاختبار والتطوير ومقارنة النتائج، وتشمل FastAPI وscikit-learn والنماذج المحفوظة.

لتشغيلها محليًا:

```bash
python -m pip install -r requirements.txt
python run_haris.py
```

ثم افتحي:

```text
http://127.0.0.1:8000
```

## ملاحظات مهمة

- البيانات الحالية افتراضية وليست قادمة من حساسات كهربائية حقيقية.
- النسخة العامة على GitHub Pages تستخدم تنفيذ Isolation Forest داخل JavaScript ومدربًا على بيانات تشغيل طبيعية مولدة داخل المتصفح.
- نسخة Python/scikit-learn الأصلية باقية في المستودع كمرجع تطويري.
- توصيات السلامة في النموذج للعرض التجريبي ولا تستبدل فحص مختص كهربائي مؤهل.
