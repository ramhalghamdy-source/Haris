# HARIS Virtual Live v1.3

نسخة عرض محلية تعمل ببيانات حساسات افتراضية لأربعة خطوط كهربائية، تمرر كل قراءة إلى نموذج Isolation Forest خاص بالخط ثم تعرض الحالة والتشخيص مباشرة.

## ما الجديد في v1.3
- رسم حي مصغر داخل بطاقة كل خط لدرجة الشذوذ Anomaly Score.
- رسم حي تفصيلي للخط المحدد: الجهد + التيار + الحرارة.
- شريط تنبيه مرئي تلقائي عند التحذير أو الخطر.
- سجل أحداث يسجل اكتشاف العطل، تصاعده إلى خطر، ثم العودة إلى الطبيعي.
- ما زالت سيناريوهات العرض الأربعة موجودة: حمل زائد، هبوط جهد، ارتفاع جهد، ارتفاع حرارة.
- الواجهة لا تعتمد على Google Fonts أو CDN أو أي مكتبة JavaScript من الإنترنت.

## هل يعمل بدون إنترنت؟
نعم. بعد تثبيت متطلبات Python على اللابتوب مرة واحدة، تشغيل التطبيق واستخدام الداشبورد والنموذج والرسوم وسيناريوهات الأعطال لا يحتاج اتصال إنترنت. العنوان `http://127.0.0.1:8000` هو اتصال محلي داخل نفس الجهاز وليس موقعًا على الإنترنت.

مهم: خطوة `setup_windows.bat` الأولى قد تحتاج إنترنت لتنزيل مكتبات Python إذا لم تكن مثبتة. بعد نجاحها مرة واحدة يمكنك اختبار العرض بوضع الطيران.

## التشغيل على Windows
1. فكّي ضغط الملف كاملًا في مجلد عادي.
2. إذا سبق أن شغلتِ setup في النسخة السابقة على نفس Python، غالبًا لا تحتاجين إعادته. وإلا شغّلي `setup_windows.bat` مرة واحدة.
3. شغّلي `start_haris.bat`.
4. اتركي نافذة CMD مفتوحة.
5. إذا لم يفتح المتصفح تلقائيًا افتحي Chrome أو Edge واكتبي: `http://127.0.0.1:8000`

## اختبار الديمو
- تأكدي أن رقم القراءة # يزيد كل ثانية.
- اختاري أي بطاقة لرؤية الرسم الحي الخاص بها.
- اضغطي `حمل زائد · المقابس` مثلًا.
- راقبي ارتفاع القراءات، ظهور شريط التنبيه، تغير البطاقة إلى تحذير/خطر، وظهور الحدث في سجل الأعطال.
- اضغطي `إعادة للوضع الطبيعي` لمسح السيناريو وسجل الأحداث وبدء عرض نظيف.

## اختبار Offline قبل يوم التحكيم
1. شغّلي HARIS مرة وهو يعمل طبيعيًا.
2. أغلقيه بـ Ctrl+C.
3. فعّلي Airplane Mode وأوقفي Wi‑Fi.
4. شغّلي `start_haris.bat` من جديد.
5. افتحي `http://127.0.0.1:8000` واختبري سيناريوهين على الأقل.

إذا نجح هذا الاختبار، فالعرض الأساسي لا يعتمد على الإنترنت.
